FREQUENTLY ASKED QUESTIONS

Answers from the Engineering Team

Does Auto Failover guarantee zero dropped calls?

No system can guarantee 100% unconditional zero socket drop when changing Layer-3 network routes. Auto Failover optimizes early degradation detection and ultra-fast path switching to minimize disruption and maximize session continuity across Zoom, OBS, and Teams.

Why doesn't the preferred Ethernet immediately take over when restored?

To prevent route flapping. A restored link enters READY first during a stabilization cooldown. Takeover requires candidate_score >= active_score + takeover_margin.

Is the desktop app separate from this website?

Yes! The desktop app is the real Python + CustomTkinter production runtime performing actual native OS network routing. This website serves documentation, product marketing, and release downloads.
